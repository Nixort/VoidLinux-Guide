# VoidLinux-Guide — Setup Stage

The setup stage turns the newly installed base system into a usable administrator workstation without adding a graphical environment yet.

## Guides

| Guide | Purpose |
|---|---|
| [First Boot](first-boot.md) | Update XBPS and establish a clean baseline. |
| [Users and Sudo](users-and-sudo.md) | Use an ordinary user safely and configure `wheel`. |
| [Locale and Time](locale-and-time.md) | Configure language, timezone and NTP. |
| [Firmware and Microcode](firmware-and-microcode.md) | Handle firmware and CPU microcode by hardware. |

Complete this stage before installing a desktop environment. A known-good console baseline makes later UI and audio failures easier to isolate.
