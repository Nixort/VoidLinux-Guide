# VoidLinux-Guide — Networking Stage

Choose one network manager for each interface. Void installs `dhcpcd` enabled by default; NetworkManager, `wpa_supplicant`, `iwd` and ConnMan are alternatives with different ownership and service requirements.

| Guide | Purpose |
|---|---|
| [Network Models](network-models.md) | Understand DHCP, static configuration and manager ownership. |
| [NetworkManager](networkmanager.md) | Configure Ethernet/Wi-Fi with D-Bus and runit. |
| [Wi-Fi and Diagnostics](wifi-and-diagnostics.md) | Check rfkill, interfaces, routes and DNS. |
