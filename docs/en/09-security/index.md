# VoidLinux-Guide — Security Stage

Security is a set of maintained choices, not one package. Keep the system updated, minimize enabled services, use least privilege, protect remote access and add enforcement mechanisms only when their operational cost is understood.

## Guides

| Guide | Purpose |
|---|---|
| [Security Baseline](security-baseline.md) | Users, permissions, updates and listening-service review. |
| [Firewall](firewall.md) | Select and verify `iptables` or `nftables`. |
| [AppArmor](apparmor.md) | Enable mandatory access control with a rollback plan. |
