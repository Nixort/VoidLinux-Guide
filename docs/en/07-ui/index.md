# VoidLinux-Guide — UI Stage

A graphical setup is a composition of GPU drivers, a display protocol, seat/session management, a desktop environment or window manager, fonts, input and optional display manager. Install one layer at a time and verify it before adding the next.

## Guides

| Guide | Purpose |
|---|---|
| [UI Architecture](ui-architecture.md) | Understand how drivers, Xorg/Wayland and sessions fit together. |
| [Xorg](xorg.md) | Install and test a traditional X session. |
| [Wayland](wayland.md) | Install and test a compositor or Wayland desktop session. |
| [Session and Display Manager](session-and-display-manager.md) | Configure D-Bus, seats, elogind/seatd and graphical login. |
